# Media / Materiały

Zrzuty i nagrania pokazujące moda w akcji. README w katalogu głównym ma gotowe, zakomentowane
linie — wrzuć plik pod jedną z nazw poniżej i odkomentuj odpowiednią linię w `README.md`
**oraz** w `README.en.md`.

*Screenshots and recordings of the mod in action. Both root READMEs already contain commented-out
embeds — drop a file under one of the names below and uncomment the matching line in `README.md`
**and** `README.en.md`.*

| Plik / File | Co pokazuje / What it shows |
|---|---|
| `hero.gif` | Główny obrazek na górze README — lista skinów na czacie / hero image: the in-chat list |
| `browser.gif` | Przeglądanie biblioteki: strony, grupowanie, klikanie / browsing: pages, grouping, clicking |
| `skin-change.gif` | `/skin <nazwa>` i zmiana wyglądu postaci / `/skin <name>` and the model changing |

## Wskazówki / Tips

- **GIF** renderuje się w README wszędzie; celuj w szerokość ~720 px i < 10 MB
  (dłuższe nagrania tnij albo przyspieszaj).
  *GIFs render everywhere; aim for ~720 px wide and under 10 MB.*
- **MP4 nie renderuje się z plików w repo.** Dłuższe demo wgraj jako załącznik do wydania
  albo przeciągnij do zgłoszenia/PR-a na GitHubie i wklej otrzymany link do README —
  wtedy GitHub pokaże odtwarzacz.
  *MP4 files stored in the repo do not render. Attach longer demos to a release, or drag them
  into a GitHub issue/PR and paste the resulting link into the README to get a player.*
- Nagrywaj na serwerze testowym z kilkoma skinami od różnych autorów — grupowanie po autorze
  jest wtedy widoczne.
  *Record on a test server with skins from a few different authors so the grouping is visible.*
